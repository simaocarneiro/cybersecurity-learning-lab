** Cybersecurity Learning Lab **
** About **

This repository documents my hands-on cybersecurity learning journey through 30 projects, organized into three difficulty levels.

The goal is to develop practical skills in Linux security, networking, security automation, vulnerability assessment, and penetration testing in controlled lab environments.

** Project Roadmap **
** Beginner **
Foundational projects focused on Linux, basic security controls, networking, and system administration.
	- Project 01 - Linux Security Checklist

** Intermediate **
Projects focused on security automation, network analysis, vulnerability assessment, and defensive security tools.

*More projects will be added as the learning journey progress.*

** Advanced **
Projects focused on advanced security testing, penetration testing methodologies, and complex lab environments.

*More projects will be added as the learning journey progress.*

- *Operating System:* Ubuntu 26.04.1 LTS

- *Version Control:* Git and GitHub

** Methodology **
Each project aims to document:

- Objectives and scope
- Tools and commands used
- Practical results and evidence
- Security findings
- Recommendations and limitations

All security testing is conducted in authorized, controlled environments.
