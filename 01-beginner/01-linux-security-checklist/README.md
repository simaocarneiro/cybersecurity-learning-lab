** Project 01 - Linux Security Checklist **

** Objective **
Perform a basic security assessment of an Ubuntu Linux system by reviewing important security configurations and documenting the results.

** Environment **
- *Operating System:* Ubuntu 26.04.1 LTS
- *Kernel:* 7.0.0-38-generic
- *Virtualization:* VirtualBox

** Assessment Areas **
- Identify the lab environment
- Check for available software updates
- Review users and permisiions
- Inspect listening network services
- Review firewall configuration
- Review SSH security settings

** Current Findings **
The intial assessment identified the operating system, kernel, and Git version.

The APT update check reported no available package upgrades at the time of testing.

These results are limited to the check performed so far and do not establish that the system is fully secure.

** Methodology **
Each check documents its objective, commands, observed results, findings, recommendations, and limitations.

** Disclaimer **
This project is intended for educational purposes and is performed in a controlled lab environment.
